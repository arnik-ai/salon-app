# Salon Telegram Mini App (demo)

Single-page Mini App (plain HTML, no build). Opens inside Telegram from a bot's menu button.
Four-step booking: service (with hair colour swatches and an optional style photo), stylist (with days off),
day on a Shamsi calendar and a time slot that fits the service length, then details and a 200,000-toman deposit.
My appointments with a reminder preview and cancellation (deposit back up to 24 hours before), a portfolio
that books the same look, and a price list with instant answers.
Sample data only. PREVIEW = true: bookings and payments send nothing yet.
